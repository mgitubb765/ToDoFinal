# To Do List App, ToDoMVC - Spring Boot + ThymeLeaf

## Description

My final project for ***CPT 245 - Java Programming*** is a complete and minimalistic ToDo List web application built by using **Spring Boot**, **Spring Data JPA**, and **ThymeLeaf**. This application follows the **MVC (Model-View-Controller)** design, and uses Bootstrap for styling.

My application allows users to <ins>add new tasks</ins>, <ins>delete tasks</ins>, and <ins>view all tasks on a single page</ins> on a simple web interface without the need for a separate front end.

---

## Features

- 👁️ View all ToDo objects on the home page
- ➕ Add new tasks
- ☑️ Mark tasks as completed or uncompleted
- ⛔ Delete individual tasks
- 🖌️ Bootstrap 5 styling
- ⚠️ Form validation with user-friendly error messages

## Tech Stack

- **Java 17+**
- **Spring Boot**
- **Spring MVC**
- **Thymeleaf** 
- **Spring Data JPA**
- **H2 Database**
- **Bootstrap 5**
